Why the file is committed
-------------------------
AGENTS.md section 3.2: Deck makes no network requests, ever - not for fonts.
The font is fetched once at build-authoring time (this file records exactly
what was fetched and from where) and is then served from the extension bundle.
There is no Google Fonts link, no CDN and no runtime download.

To reproduce
------------
  npm pack @fontsource-variable/inter@5.3.0
  tar -xzf fontsource-variable-inter-5.3.0.tgz
  cp package/files/inter-latin-wght-normal.woff2 \
     apps/extension/src/assets/fonts/inter-latin-variable.woff2

The unicode-range in global.css is copied verbatim from the package's wght.css
latin block, so the subset the browser is told about matches the subset shipped.
